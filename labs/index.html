HANDS-ON LABS

Hands-on labs

Learn an Atlas attack by reproducing it on your own machine. Each lab runs locally in Docker, ends every "successful attack" in a harmless canary, ships an animated explainer, and closes with a defense chapter. Each lab page holds the explainer and the full lab guide; the code you run lives in labs/ on GitHub. Browse the explainers by tag. If ML or statistics terms are new to you, the primers define each one in plain words.

60 of 100 planned labs built. See the labs roadmap for what comes next.

Take the labs in this order. Each module builds on the ones before it. The LAB number is only the order the labs were built in. Levels: beginner needs only appsec, Docker and Python; intermediate uses terms an earlier module teaches; advanced combines several modules.

Module 0 Setup and orientation

about 30 min Every laptop has the workbench image, the HF cache volume pre-seeded and, only for tracks that need one, a model backend. Read the payload-safety note and the Start here steps at the top of the labs index (labs/README.md). If ML or statistics terms are new to you, skim the primers: the labs link each term to its definition there. This module has no lab of its own.
