Gradient-based adversarial perturbations / FGSM

Specify perturbation set, preprocessing and target task.

Use input gradients to find perturbations that affect predictions.

AI-generated draft · conceptual overview, not yet reviewed

Gradient-based adversarial perturbations use a model’s own input gradients to find small changes that alter its predictions. The classic single-step form illustrates the principle: move the input in the direction that most increases the model’s loss. It routes toward evading security controls or accountability and manipulating outputs, predictions or decisions.

Conceptually the technique depends on losses, gradients and optimization: differentiability lets an attacker compute how each input feature influences the output and perturb accordingly. The attacker-controlled input is the perturbation added to a sample; the victim-controlled state is the neural network whose decision boundary is being probed. Access assumptions matter — computing gradients directly implies white-box or surrogate access, which should be stated rather than assumed.

Scoping is essential: the perturbation set, any input preprocessing, and the target task must be specified, since a perturbation valid under one norm and pipeline may not survive another. This single-step method is foundational and is required by stronger relatives — iterative projected adversarial optimization, optimized visual jailbreaks, and physical-world adversarial examples — which build on the same gradient signal.

The candidate mitigation is adversarial training and robustness evaluation, which improves resistance under a stated threat model without guaranteeing robustness generally; it should be paired with adaptive defense evaluation. Evaluation also uses attack success and severity and an explicit threat model. For measured robustness figures, defer to the cited source.
