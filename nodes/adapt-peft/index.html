Parameter-efficient fine-tuning

Adapt a subset or added parameters rather than all model weights.

AI-generated draft · conceptual overview, not yet reviewed

Parameter-efficient fine-tuning (PEFT) is a family of adaptation methods that adjust a subset of a model’s parameters, or a small set of newly added ones, instead of updating every weight. By keeping the large base model frozen and training only a compact set of parameters, PEFT reduces compute, memory and storage requirements while still specializing behavior for a task or domain. Foundational examples are described in LoRA: Low-Rank Adaptation of Large Language Models and QLoRA: Efficient Finetuning of Quantized LLMs.

As an approach, PEFT builds on supervised fine-tuning: a training signal defines the target behavior, but only the efficient parameter set is optimized against it. This framing makes PEFT the umbrella under which several concrete techniques sit, including LoRA, prefix tuning and soft prompt tuning, each of which chooses a different small set of parameters to learn.

PEFT is a neutral, widely used engineering pattern; whether any given adaptation is benign depends on its data, objective and deployment. Its efficiency also makes many task-specific adapters practical to distribute, which places integrity and provenance of those adapters in scope. Specific trade-offs against full fine-tuning are documented in the cited sources.
