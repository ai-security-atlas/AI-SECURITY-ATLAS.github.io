Extraction fidelity versus artifact equality

Compare functional agreement, task quality and parameter recovery without conflating them.

AI-generated draft · conceptual overview, not yet reviewed

Extraction fidelity versus artifact equality distinguishes several things a model-stealing result might claim, which are easy to conflate. Functional agreement (does the copy produce the same outputs as the target?), task quality (is the copy good at the task, regardless of matching the target?), and parameter recovery (are the actual weights or a specific component reconstructed?) are separate axes. A copy can agree closely on outputs while sharing no parameters, or recover part of a model without matching its full behavior.

What it evaluates

This measure applies to extraction and theft techniques where the nature of the “stolen” artifact matters: black-box functional model extraction, partial parameter recovery from API behavior, unauthorized checkpoint or adapter theft, and unauthorized teacher-student capability transfer. Each targets a different point on the fidelity-versus-equality spectrum.

A common pitfall is reporting high output agreement as if it were weight recovery, or task quality as if it were faithful imitation of the target. Fidelity results are scope-limited: they hold for the queried input distribution and measurement metric, and high agreement there is not proof the extracted artifact matches the original everywhere or that theft of the full model has occurred. Choosing a metric appropriate to the claimed threat is essential. Defer to the cited sources for concrete fidelity measurements and the query regimes under which they were obtained.
