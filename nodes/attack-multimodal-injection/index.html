Instructions carried through multimodal content

This is a scope-level extension; a visual adversarial perturbation is a separate mechanism.

Lower-trust visible text or interpreted media can become instructions in a multimodal workflow.

AI-generated draft · conceptual overview, not yet reviewed

Instructions carried through multimodal content extend prompt injection beyond plain text: visible text within an image, or media a model interprets, can be absorbed as instructions inside a multimodal workflow. The objective is to cause unauthorized actions or to manipulate outputs, predictions or decisions.

How it works

The technique relies on a failure of trust boundaries and authorization in systems built on vision-language models. Content that should be treated as lower-trust data — for example, text rendered inside a picture, or a document surfaced by a browser or computer-use integration — can instead be read by the model as an authoritative directive. The attacker controls the content of the media; the victim system controls whether that content is granted instruction-level trust. The gap between those two is the mechanism.

This is a scope-level extension of prompt injection into additional modalities. It is conceptually distinct from an optimized visual adversarial perturbation, which manipulates model behavior through imperceptible pixel changes rather than through readable content.

Exposure depends on where multimodal inputs enter — browser and computer-use integrations are a common surface — and on how those inputs are attributed and authorized.

Evaluation is framed through an explicit threat model and attack success and severity. For empirical framing, defer to the cited indirect-injection and visual-instruction sources rather than assuming any specific system behaves this way today.
