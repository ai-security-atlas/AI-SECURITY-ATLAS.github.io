Unauthorized factual model editing

ROME is neutral research; unauthorized application is the threat scenario and needs separate authorization context.

Modify selected model associations to influence later answers.

AI-generated draft · conceptual overview, not yet reviewed

Unauthorized factual model editing modifies selected internal associations so that the model returns attacker-chosen answers to later queries. It routes toward establishing persistent attacker influence and manipulating outputs, predictions or decisions, because the change is written into the model’s parameters rather than supplied at inference time.

Conceptually the technique applies targeted model editing — methods that locate and rewrite specific factual associations in a language model — to alter a chosen fact while leaving unrelated behavior largely intact. The attacker-controlled input is the edit specification (which association to change and to what); the victim-controlled state is the model whose weights are modified and every downstream user who queries it afterward. A defining caveat is that targeted-editing research is itself neutral; the threat arises only when such an edit is applied without authorization, which requires its own access and authorization context to be established.

This sits in the representation-and-weight-interventions family alongside merge- and conversion-based tampering, which introduce untrusted changes through different artifact operations.

The atlas lists no dedicated mitigation node for this entry; the mechanism points toward provenance, change control over weights, and regression testing of factual behavior. Evaluation is framed through attack success and severity under an explicit threat model. For the specific editing method and its demonstrated precision and side effects, defer to the cited source.
